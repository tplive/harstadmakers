# Harstad Makers
Harstad Makers er et makerspace for kunst og håndverk, elektronikk, 3d-print og data - interesserte.

Dette repoet inneholder våre åpne og offentlig tilgjengelige kode-prosjekter.

Repoet er under MIT lisens, det vil si at alt du finner her kan brukes til hva du vil, men du må oppgi oss som kilde.
